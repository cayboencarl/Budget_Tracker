# Flask-Migrate
-Migrations are like "version control for your database schema."

Step 1: Install Flask-Migrate
pip install flask-migrate

Step 2: Set up migrations in your app.py
Import Migrate from flask_migrate (from flask_migrate import Migrate)
Create a Migrate object that connects Flask, SQLAlchemy, and the migration system (migrate = Migrate(app, db))
Initialize it with your app and db ((app, db))

Step 3: Initialize the migration folder
From your terminal (in your backend folder), run:
-flask db init-
This creates a migrations folder that will track all your schema changes.

Step 4: Create an initial migration
Run:
flask db migrate -m "Initial migration: create transactions table"
This creates a migration file that describes your current schema.

Step 5: Apply the migration
Run:
flask db upgrade
This applies the migration (though the table already exists from db.create_all()).

#Migration Commands
flask db init — initialize the migration system (do this once)
flask db migrate — create a new migration based on model changes
flask db upgrade — apply migrations to the database
flask db downgrade — undo the last migration
